Xubuntu Backup

Xubuntu Backup is a personal backup workflow intended for its owner's computer and Google Drive account. It uses Restic to encrypt backup contents locally and Rclone to transfer the encrypted repository to Google Drive.

The Google OAuth client is used to authorize Rclone. It requests the limited drive.file permission to manage files created by this app or explicitly made accessible to it. Each backup runs only when the owner chooses to run it.

This is not a public backup service and does not accept other users' files or credentials.
